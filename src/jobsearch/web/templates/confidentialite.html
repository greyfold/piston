C'est une protection par balises, pas un anonymat : un parcours détaillé reste reconnaissable par qui le cherche. C'est pourquoi il ne part que vers ton propre compte Claude, jamais vers un autre service.

Comment l'IA travaille

  • Avec ton abonnement Claude, sans clé API ni intermédiaire.{% if moteur and moteur.connecte %} connecté{% endif %}
  • Sans aucun outil pour noter les annonces et écrire les dossiers : ni fichiers, ni Internet, ni tes réglages, extensions ou connecteurs Claude.
  • Consigne dans un fichier temporaire lisible de ton seul compte, effacé après la tâche : rien de ton profil n'apparaît dans la liste des processus.
  • Dans la machine virtuelle, toujours : Claude Code et son Chrome y tournent, jamais sur ton Mac. Elle ne voit qu'un dossier d'échange (jeton, journaux, ce qu'une tâche lui confie) ; ni ta base, ni ton profil, ni ton dossier personnel, ni ton trousseau, ni Mail, ni ton Chrome à toi.
  • Rien n'est envoyé à un employeur sans toi : tu relis, tu envoies.

Les exceptions, que tu déclenches

  • Remplir un formulaire ou saisir une preuve Job-Room avec Claude : Claude tape tes vraies coordonnées dans la page de l'employeur ou de Job-Room, dans le Chrome de la machine virtuelle. Il doit les voir pour les saisir. Il ne le fait que quand tu le lui demandes ; le pré-remplissage sans Claude, lui, les saisit sans l'IA.
  • Gmail, s'il est activé : la session Claude qui interroge ta boîte voit les messages liés à tes candidatures. Le tri des réponses se fait ensuite sur ton Mac. Apple Mail, lui, est lu sur ton Mac, sans l'IA.

Ton réglage chez Claude

Dans claude.ai → Paramètres → Confidentialité, désactive « Aider à améliorer Claude » si tu ne veux pas que tes échanges servent à entraîner les modèles. Ce réglage vaut aussi pour la plateforme, qui passe par ton compte.
