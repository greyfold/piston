C'est une protection par balises, pas un anonymat : un parcours détaillé reste reconnaissable. C'est pourquoi il ne part que vers ton propre compte {{ ia.nom }} ({{ ia.editeur }}), le moteur que tu as choisi, jamais vers un autre service.

Comment l'IA travaille

  • Avec ton abonnement {{ ia.abonnement }}, par la commande de code de {{ ia.editeur }}, sans clé API ni intermédiaire.
  • Sans aucun outil pour noter les annonces et écrire les dossiers : ni fichiers, ni terminal, ni Internet, ni tes réglages, extensions ou connecteurs {{ ia.nom }}.
  • Consigne dans un fichier temporaire lisible de ton seul compte, effacé après la tâche : rien de ton profil n'apparaît dans la liste des processus.
  • Ni télémétrie ni rapports d'erreur : l'application les coupe chez chaque moteur ; seule ta demande part vers {{ ia.editeur }}.
  • Dans la machine virtuelle, toujours : {{ ia.nom }} et son Chrome y tournent, jamais sur ton Mac. Elle ne voit qu'un dossier d'échange (jeton, journaux, ce qu'une tâche lui confie) ; ni ta base, ni ton profil, ni ton dossier personnel, ni ton trousseau, ni Mail, ni ton Chrome à toi.
  • Rien n'est envoyé à un employeur sans toi : tu relis, tu envoies.

Les exceptions, que tu déclenches

  • Remplir un formulaire avec {{ ia.nom }} : l'IA tape tes vraies coordonnées dans la page de l'employeur, dans le Chrome de la machine virtuelle. Elle doit les voir pour les saisir, et ne le fait que quand tu le lui demandes. Elle n'a que deux outils, fixés par l'application : piloter ce Chrome (sans exécuter de script) et lire ce que la tâche lui confie. Le pré-remplissage sans IA, lui, les saisit sans elle.
  • Gmail, s'il est activé : la session Claude qui interroge ta boîte voit les messages liés à tes candidatures. Le tri des réponses se fait ensuite sur ton Mac. Apple Mail, lui, est lu sur ton Mac, sans l'IA.{% if ia.id != "claude" %} Gmail et Indeed sont des connecteurs du compte Claude : ils ne servent qu'avec Claude, pas avec {{ ia.nom }}.{% endif %}
